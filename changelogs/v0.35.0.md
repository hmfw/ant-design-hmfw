# v0.35.0 (2026-08-03)

## 🧭 Tour 定位重写与 Button class 合并修复

本版本重写 Tour 的定位与遮罩实现，修复高亮框在页面滚动后错位、组件实例作为 `target` 时崩溃等问题，并对齐 AntD 的 `gap` / `disabledInteraction` 语义。同时修复 Button 一个影响全局的 class / style 覆盖缺陷。

### 🐛 缺陷修复

#### Button 透传 class / style 覆盖组件自身样式（影响面广）

- **Button**: 修复外部透传的 `class` 会整体覆盖组件内置 class 的问题
  - 根因：`...attrs` 展开位置在 `class` / `style` 之后，外部值直接替换而非合并
  - 表现：`<Button class="foo">` 渲染后 DOM 上只剩 `foo`，`hmfw-btn` 基类丢失，按钮退化为浏览器默认样式（灰底、无圆角）
  - 同一原因导致外部 `style` 覆盖 `styles.root`
  - 修复：将 `class` / `style` 从 attrs 展开中摘出，交由 Vue 隐式 attrs 继承合并
  - `href` 模式（渲染为 `<a>`）存在同样问题，一并修复

#### Tour 定位

- **Tour**: 修复页面滚动后弹层与高亮框相对目标元素错位
  - 根因：视口坐标与文档坐标混用
  - 统一采用视口坐标系 + `position: fixed`
- **Tour**: 修复传入 Vue 组件实例作为 `target` 时抛错
  - 新增 `getTargetEl` 统一解包，支持 CSS 选择器 / HTMLElement / 组件实例（`$el`）/ 返回上述值的函数
- **Tour**: 无 `target` 的步骤改为视口居中展示并抑制箭头（对齐 AntD `placement: 'center'`）
- **Tour**: 弹层超出视口时自动向对侧翻转，并保留 8px 视口安全边距
- **Tour**: `scroll` / `resize` 监听改为 requestAnimationFrame 合帧，`scroll` 采用捕获阶段以响应内层滚动容器；卸载时清理监听并取消未执行帧

#### Tour 箭头

- **Tour**: 补齐箭头渲染 —— 此前 `arrow` 配置无任何视觉效果
- **Tour**: 支持 `arrow.pointAtCenter` 指向高亮区域中心
- **Tour**: 新增步骤级 `arrow` 配置，优先级高于 Tour 级

#### 文档站示例

- **Tour**: 修复「带封面的引导」三张封面图 404（原 CDN 路径已下线），替换为实测可访问的横向图
- **Tour**: 修复 `TourPlacement` / `TourNonModal` 中 `icon="ellipsis"` 传字符串导致的 Vue 渲染告警，改为传入图标组件

### ✨ 新增功能

- **Tour**: 新增 `disabledInteraction` 属性，控制是否禁用高亮区域的交互（默认 `false`，高亮元素可正常点击）
- **Tour**: 新增 `TourInteraction` 示例，演示高亮元素可交互与禁用交互两种模式
- **Tour**: 遮罩填充色改为走 `--hmfw-tour-mask-color` Token，补齐暗色主题适配（`mask.color` 显式指定时仍优先）
- **Tour**: `classNames` / `styles` 新增 `arrow` 语义化插槽
- **Tour**: 导出 `TourRenderable` / `TourArrow` / `TourMask` / `TourGap` 类型
- **Tour**: `getPopupContainer` 签名补齐 `triggerNode` 参数，`indicatorsRender` 返回值放宽至 `VNode | string | number`

### ♿ 无障碍

- **Tour**: 弹层补齐 `role="dialog"` / `aria-modal`，标题与描述通过 `aria-labelledby` / `aria-describedby` 关联
- **Tour**: 打开时移入焦点、关闭后归还至触发元素
- **Tour**: 步骤指示器补齐 `aria-label` 与 `aria-current`

### 🔧 重构

- **Tour**: 单文件拆分为 `Tour.tsx`（387 行）+ `TourPanel.tsx`（170 行）+ `TourMask.tsx`（97 行）+ `utils.ts`（221 行），定位计算下沉为纯函数便于单测

### ⚠️ 破坏性变更

- **Tour**: `gap` 语义对齐 AntD，默认值随之变化
  - `gap.offset` 默认 `12` → `6`，`gap.radius` 默认 `4` → `2`
  - `gap.offset` 此前同时影响高亮框外扩与弹层间距，现仅控制高亮框外扩；弹层与高亮区域的间距固定为箭头尺寸
  - 影响：未显式配置 `gap` 的使用方会看到高亮框边距和圆角略微收紧。如需保持原观感，显式传入 `gap={{ offset: 12, radius: 4 }}`
