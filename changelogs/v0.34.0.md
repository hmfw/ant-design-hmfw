# v0.34.0 (2026-08-03)

## 🎨 暗色主题全面适配

本版本系统性解决暗色模式下的色彩适配问题，使所有组件正确响应 ConfigProvider 的主题配置，不再与系统配色混淆。

### 🐛 缺陷修复

#### ConfigProvider 响应式修复

- **Empty / Result / Skeleton**: 插画配色从 `@media (prefers-color-scheme: dark)` 媒体查询改为由全局 Token 派生
  - 修复：原先跟随系统配色，与 ConfigProvider 主题相互独立，"系统暗色 + 应用浅色"时插画会单独变深的冲突
  - Empty: `img-shadow` / `img-outline` / `img-bg` 分别映射到 `fill-tertiary` / `border` / `fill-quaternary`
  - Result: `img-shadow` / `img-text` 映射到 `fill-tertiary` / `text-quaternary`
  - Skeleton: `image-path` 映射到 `text-quaternary`，移除 `:root` 上的媒体查询（避免污染全局 token）
  - 保留显式主题类（`.hmfw-theme-dark` / `[data-theme]`）作为局部强制覆盖钩子

#### 白底白字修复

- **Layout**: 修复 `sider-light` 的 trigger 在暗色下白底白字不可读的问题
  - `sider-light .hmfw-layout-sider-trigger` 和 `.hmfw-layout-sider-zero-width-trigger` 的背景从 `#fff` 改为 `var(--hmfw-color-bg-container)`
  - 深色 sider 的 trigger 文字色从 `#fff` 改为 `var(--hmfw-color-text-light-solid)`（语义更准，取值不变）

#### 骨架屏统一

- **Card**: loading 骨架渐变从写死的 `rgba(0,0,0,0.06→0.15)` 改为复用 Skeleton 的 `--hmfw-skeleton-color-base` / `-highlight`
  - 修复：暗色下黑渐变压黑底，动画完全不可见
  - 统一 Card 和 Skeleton 的骨架观感

#### Token 体系接入

- **Calendar**:
  - 全屏模式底色 `--hmfw-calendar-full-bg` 从 `#ffffff` 改为 `var(--hmfw-color-bg-container)`
  - 范围选择首尾格文字色从 `#fff` 改为 `var(--hmfw-color-text-light-solid)`
  - 删除 23 个从未被引用的死变量声明（仅保留 4 个实际使用的）

- **Typography**:
  - `code` 的背景从 `rgba(150,150,150,0.1)` 改为 `var(--hmfw-color-fill-tertiary)`，边框从 `rgba(100,100,100,0.2)` 改为 `var(--hmfw-color-border)`
  - `kbd` 的背景从 `rgba(150,150,150,0.06)` 改为 `var(--hmfw-color-fill-quaternary)`，边框同上
  - 修复：原中性灰技术上明暗两套可见，但绕过 Token 体系，换品牌色或自定义主题时不跟随

### ✨ 新增功能

#### 暗色算法

- **主题系统**: 四色语义色阶（primary / success / warning / error）实现暗色感知
  - 新增 `getLuminance()` 计算相对亮度（WCAG 2.0 标准）
  - 新增 `isDark()` 判断背景是否为暗色（相对亮度 < 0.5）
  - `colorBgBase` 暗色时，`*Bg` / `*BgHover` / `*Border` 从 `lighten` 翻转为 `darken`
  - 暗色下取值示例：`colorPrimaryBg: #07244c`（原 `#e8f1ff` 浅蓝 → 深蓝）
  - 影响 14 个组件的选中项底色：AutoComplete / Calendar / Cascader / DatePicker / Select / Mentions / Table / Tabs / Menu / Steps / Tree / TreeSelect / Pagination / Transfer
  - 修复：原先所有主题只生成一套浅色调，暗色下选中块是浮着的亮蓝斑

#### 对比度优化

- **Rate**: 未选中星底色从 `fill-content`(0.06) 提升到 `fill`(0.15)
  - 修复：空星是细线图形，0.06 在暗底上几乎不可见
  - 浅色下叠白底 = `#d9d9d9`（border 同值），暗色下 = `rgba(255,255,255,0.15)`

### 🧹 代码清理

- **Calendar**: 删除 23 个从未被任何文件引用的 CSS 变量声明（原 27 个变量中仅 4 个被使用）
