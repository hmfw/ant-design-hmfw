# v0.36.0 (2026-08-04)

## 🔧 Trigger 内部原语全面修复

本版本针对 `Trigger` 内部原语进行全面审查与修复，解决 11 个涉及事件幂等性、定位同步、资源泄漏、键盘交互的缺陷。Trigger 是 Dropdown / Tooltip / Select / Popover / Cascader / DatePicker / SubMenu 等组件的底层定位引擎，此次修复提升全体消费组件的稳定性与体验一致性。

### 🐛 缺陷修复

#### P0：核心正确性

- **Trigger**: 修复 `setOpen` 重复触发 `openChange` 事件
  - 根因：鼠标从触发器移入弹层时未合并状态变更，重复 emit `(true)`
  - 表现：`mouseenter` 延迟未到即 `mouseleave` 时，emit 虚假的 `openChange(false, {source: 'trigger'})`
  - 影响：外部 `open` 受控时产生闪烁，嵌套弹层关闭时机错乱
  - 修复：新增 `_pendingOpen` 缓冲下一帧状态，相同值合并为单次 emit；`focusin` 判重防止重复打开

- **Trigger**: 修复 `placement` 动态变更时弹层坐标与 class 不匹配
  - 根因：`placement` watch 只更新 class，未触发重新定位
  - 表现：`placement: 'bottom'` 改为 `'top'` 后弹层仍在下方，但方位 class 已变为 `hmfw-trigger-placement-top`
  - 影响：箭头方向与实际位置错配，消费组件无法通过动态 `placement` 切换弹层位置
  - 修复：`placement` watch 内调用 `updatePosition()` 同步重新定位

- **Trigger**: 修复 `enterTimer` / `leaveTimer` 堆积与泄漏
  - 根因：连续 `mouseenter` 未清除上一个 `enterTimer`，`unmount` 未清理延迟句柄
  - 表现：快速划过触发器多次，产生多个并行定时器，造成延迟后重复打开或关闭
  - 影响：hover 触发行为不符合预期，卸载组件后定时器仍执行导致 `emit` 抛错
  - 修复：每次新建前清理同名 timer，`onBeforeUnmount` 清理全部延迟句柄

#### P1：用户可见缺陷

- **Trigger**: 修复 `afterOpenChange` 过渡定时器未纳入卸载清理
  - 根因：`transitionTimer` 句柄未存储，卸载时无法取消
  - 表现：组件卸载后定时器仍触发 `emit('afterOpenChange')`，控制台警告
  - 修复：存储句柄并在 `onBeforeUnmount` 中 `clearTimeout`

- **Trigger**: 修复 `observePopupResize` 由 `false` 动态改 `true` 时永久失效
  - 根因：早期实现只在 `onMounted` 创建 observer，prop 变更不响应
  - 表现：挂载时 `observePopupResize: false`，后续改 `true` 无效，弹层尺寸变化不触发重定位
  - 影响：Cascader / Select 动态开启尺寸观察失效
  - 修复：改为 watchEffect 惰性创建，prop 变 `true` 时立即创建并 `observe`

- **Trigger**: 修复 `disabled` 变 `true` 时已打开弹层未关闭且被卡死
  - 根因：`disabled` watch 未调用 `setOpen(false)`
  - 表现：弹层保持可见，后续 Esc / 外点全被 `disabled` 守卫拦截，用户无从关闭
  - 影响：禁用状态下弹层成为僵尸节点
  - 修复：`disabled` 变 `true` 时调用 `setOpen(false, 'trigger')`

- **Trigger**: 修复 `scroll` / `resize` 事件无节流造成每次强制重排
  - 根因：每个 `scroll` / `resize` 事件同步调用 `updatePosition()`，读 `getBoundingClientRect()` → 写 `style`
  - 表现：浏览器在同一帧内多次强制布局，滚动卡顿
  - 影响：嵌套滚动容器或窗口缩放时性能劣化
  - 修复：通过 `requestAnimationFrame` 合并同一帧内的多次请求为一次重定位

- **Trigger**: 导出 `TriggerOpenChangeInfo` / `TriggerOpenSource` 类型定义
  - 根因：`types.ts` 定义但未从 `index.ts` 导出
  - 表现：消费组件（如 Dropdown）需重复定义字面量类型 `'trigger' | 'popup'`
  - 修复：从 `index.ts` 导出，Dropdown 等消费组件改为引用

#### P2：交互体验与一致性

- **Trigger**: 修复嵌套弹层 Esc 一次性关闭所有层级
  - 根因：全局 `keydown` 监听器全部同步触发
  - 表现：打开 Dropdown → 子 Select，按一次 Esc 两层同时消失
  - 影响：与原生 `<dialog>` / AntD / Floating UI 栈语义不一致
  - 修复：在 `eventManager.ts` 中实现 LIFO 栈，`Escape` 只关闭栈顶层，关闭后从栈移除

- **Trigger**: 修复 `delay` / `matchWidth` 负值未钳制
  - 根因：缺少边界校验
  - 表现：`mouseEnterDelay: -1` 生成 `setTimeout(-1)`，`matchWidth: -100` 写出 `min-width: -100px`（被浏览器丢弃）
  - 修复：`Math.max(0, delay)` / `Math.max(0, matchWidth)`

- **Trigger**: 箭头尺寸与偏移硬编码改为 Token 化
  - 根因：`16px` / `8px` 写在 `:root` 块外，未参与主题系统
  - 影响：无法通过 Token 统一调整箭头尺寸
  - 修复：定义 `--hmfw-trigger-arrow-size: 16px` / `--hmfw-trigger-arrow-offset-h: 16px` / `--hmfw-trigger-arrow-offset-v: 8px`，并在注释中说明派生规则（`offset-h = size`，`offset-v = size / 2`）

- **Trigger**: 修复 `zIndex` 未传时绕过 `--hmfw-z-index-popup` Token
  - 根因：`zIndex ?? 1050` 将 `undefined` 转为数值，写入 `style.zIndex = "1050"`
  - 影响：无法通过 ConfigProvider Token 统一调整弹层层级
  - 修复：`undefined` 时写 `var(--hmfw-z-index-popup)`，显式数值时保持原行为
  - SubMenu 硬编码 `zIndex={1050}` 一并移除，改为走 Token 默认值
