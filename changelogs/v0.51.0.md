# v0.51.0 (2026-09-30)

## ✨ 新增功能

### ColorPicker 支持受控 open 与 getPopupContainer

- 新增 `open` 受控属性与 `defaultOpen` 非受控初值，配套 `update:open` 事件，可完全接管弹层展开状态

### Modal 支持 getContainer 自定义弹层挂载容器

`getContainer` 支持字符串选择器、DOM 元素、函数与 `false`（原地渲染，不传送），默认挂载到 `body`。补充相应单元测试。

### npm 包内置 AI 离线文档

`@hmfw/ant-design` 不在大模型训练数据中，消费方项目的 AI 编码助手此前只能对着 `dist/**/*.d.ts` 猜 API——类型签名既无默认值也无用法示例（`Table` 的 JSDoc 覆盖数为 0）。现在包根直接内置两份纯文本文档：

- `llms.txt`（约 9 KB）：71 个组件的名称、一句话简介与文档链接，可整份读入
- `llms-full.txt`（约 300 KB）：自包含全量文档，含每个组件的 props / events / slots 表格与 2 个完整示例源码

配套改动：

- `scripts/generate-llm-manifest.ts` 新增 `emit()` 助手与 `--pkg` 开关，收敛原先重复的三处 `writeFileSync`；常规 `pnpm gen:llm` 保持零副作用，仅 `--pkg` 时额外写包根
- `package.json` 新增 `gen:llm:pkg` 脚本并接入 `postbuild:lib`（挂在 tsup 之后，避开 `clean` 清空 dist）；`files` 与 `exports` 各增补两项
- `llms.txt` 开头与 `## More` 段声明「完整文档就在本包内，可离线读取」，让翻 `node_modules` 的助手知道该去哪查
- `prepublish-check.ts` 的必需文件清单补充两项，避免 `files` 白名单列了但文件不存在时被 npm 静默跳过

## 🐛 问题修复

### Trigger 弹层相对定位容器时的坐标偏移

当 `getPopupContainer` 返回定位容器（`position: relative/absolute`）时，扣除该容器的文档偏移，避免弹层被推离触发器；传送到 `body` 时行为不变。

### SemanticPreview 浮层遮挡与高亮框不对称

修复浮层节点被组件 `z-index` 遮挡、高亮框左上/右下 1px 不对称的问题。

### llm manifest 正则截断与「何时使用」正文丢失

- JS 正则不支持 `\Z`（会被当成字面量 Z），改用 `$(?![\s\S])` 断言字符串结尾，避免正文在首个大写 Z 处被截断
- 新增 `sectionText` 拼接段落与列表项，修复「何时使用」纯列表段落被 `firstParagraph` 整段跳过导致正文丢失

### 文档过时数据订正

- `package.json` 的 `description` 组件数 `68` → `71`，并把中英混排的 139 字符长句精简为单句中文（57 字符）
- 首页统计数据：`66 个组件` → `71 个组件`；`65 个测试文件，655 个测试用例` → `75 个测试文件，2605 个测试用例`
- README 测试数 `2598` → `2605`

## 🔨 代码重构

### 抽出 `_hooks` 共享层

将跨组件共享的 hooks 从 `_utils` 中独立出来，使 `_utils` 回归纯函数语义：

- `useControlledState` 与 overlay 三个 hooks 移至 `components/_hooks/`，README 同步泛化为共享 hooks 说明
- Modal、Drawer、ImagePreview 的 5 处 import 收敛为 `'../_hooks'`
- CLAUDE.md 新增「跨组件共享代码放置」小节，明确 `_hooks` / `_utils` 边界与判断标准

### Button 形状样式特异性

`circle` / `round` 形状规则用 `.hmfw-btn` 叠加提高特异性，避免被尺寸规则覆盖 `border-radius`。
