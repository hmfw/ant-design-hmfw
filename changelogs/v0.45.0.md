# v0.45.0 (2026-08-16)

## 🎯 核心变更

### Grid 响应式体系升级

- **useBreakpoint 重构为模块级共享单例**（对齐 AntD `responsiveObserver` 设计）：所有使用方（Row、Pagination 等）共享同一份 matchMedia 监听，而非每实例注册一套；引用计数归零（最后一个使用方卸载）时统一移除监听并释放单例
- **新增 xxxl 断点**（`min-width: 1920px`），`Breakpoint` 类型、`responsiveMap`、响应式 class（`hmfw-col-xxxl-*` / `hmfw-col-offset-*` 补齐 0–24）全部同步
- Col 的 `span` / `offset` / `order` / `pull` / `push` 类型由 `number` 放宽为 `ColSpan`（支持 `'auto'` 等字符串值）
- 新增 `context.ts`（Row 栅格上下文），`useBreakpoint` 与 `ScreenMap` 从包入口导出
- 文档新增 3 个示例：GridFlexStretch（flex 拉伸对齐）、GridResponsiveFlex（响应式 flex 属性）、GridUseBreakpoint（useBreakpoint Hook 用法）
- Pagination 测试接入 `enableAutoUnmount`，适配单例化后的卸载隔离要求

### Cascader 多选联动与 API 补全

- **多选勾选传导**（对齐 AntD）：勾选父节点联动勾选全部后代；某节点的所有子节点勾选后父节点自动勾选，部分勾选时呈半选态
- **showCheckedStrategy 折叠策略**：`SHOW_PARENT`（父路径被选中或某节点所有子节点选中时折叠为父路径）/ `SHOW_CHILD`（仅保留叶子路径），`value` 按策略去重存储、面板渲染时传导补齐
- **fieldNames** 自定义字段映射，对接后端 `id` / `name` 等字段结构无需前端转换
- 新增 `change` / `search` / `clear` 三个事件及对应 handler 类型导出（`CascaderChangeHandler` 等）
- 文档新增 6 个示例：DefaultValue、DisabledOption、FieldNames、Lazy（loadData 动态加载）、Size、Status

### Layout Sider 语义化 API 补全

- 新增 `reverseArrow`：折叠状态箭头方向反转（`trigger` 自定义时同步生效）
- 补齐零宽触发（zero-width trigger）相关的类名与样式逻辑
- 导出 `SiderClassNames`（root / body）与 `SiderStyles` 语义化节点定义，新增 `SiderCollapseHandler`、`SiderBreakpointHandler` 回调类型
- 文档新增 3 个示例：LayoutFixed（固定头部/侧栏）、LayoutSemantic（语义化 API 定制）、LayoutTopSide（顶部-侧边布局）

### Menu 类型导出补全

- `ItemType` 此前未从包入口导出，`items` 相关类型无法在消费侧引用，本次补全
