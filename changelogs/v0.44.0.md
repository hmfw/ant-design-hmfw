# v0.44.0 (2026-08-16)

## 🎯 核心变更

### QRCode 全面重写（修复不可扫描缺陷）

原编码器存在掩码破坏定位图案、多块缺少交错、格式信息位序颠倒等规范 bug，生成的二维码**完全不可扫描**。重写为独立 `encoder.ts`，与权威实现逐位交叉验证（v1-v10 × L/M/Q/H 共 67 组用例一致）。

同步修复 SVG 偏移裁剪、icon 挖白透点、type 切换空白三个渲染问题；`onRefresh` 改为 emits（`@refresh` / `:on-refresh` 写法不变）；接入国际化（中英文文案）；props 规范化与样式 Token 化。

文档新增 6 个示例（纠错等级 / 自定义尺寸 / 下载 / 边框 / 留白 / 版本提升），API 表（refresh 事件、marginSize 说明）与设计 Token 章节同步更新。

### 组件文件结构拆分（Form / Card）

- **Form**：`FormItem` 与表单上下文拆分为独立文件（`Form.tsx` 301 行 → `FormItem.tsx` + `context.ts`），公共类型抽离至 `types.ts`
- **Card**：`CardGrid` / `CardMeta` 拆分为独立组件文件

### 渲染优化与格式精简（Menu / Empty / Drawer / Modal / Notification）

- **Menu**：class 计算提取为 computed，渲染时不再重复计算
- **Drawer / Modal**：渲染函数内 class 计算提取为局部变量（Drawer 的 header / 根节点 / content-wrapper，Modal 的 wrap 容器），JSX 结构更扁平；Drawer 根节点去除 `style={{ ...rootStyle }}` 的多余浅拷贝（`rootStyle` 本就是每次渲染新建的对象）
- **Empty / Drawer / Modal / Notification**：props 定义统一精简为单行格式，`satisfies Record<keyof XProps, any>` 类型约束保持不变
