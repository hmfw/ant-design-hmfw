# v0.53.0 (2026-10-16)

本次为 Table 表格的功能补齐与重构版本：补齐此前「类型已声明但未实现」的大量能力，修复行选择 / 固定列 / 吸顶表头等缺陷，并将 1460 行的 `Table.tsx` 拆分至 911 行。

## ✨ 新增功能

### Table 树形数据（嵌套 children）

- 数据项带 `children`（可用 `childrenColumnName` 自定义字段名）时自动进入树形模式：展开图标内嵌在数据列（`expandIconColumnIndex` 控制位置），按 `indentSize` 逐层缩进，展开时递归渲染子节点行。
- 支持 `defaultExpandAllRows`（默认全展开）、`rowExpandable`（否决某行可展开）、`expandRowByClick`（点击整行切换）、`expandIcon`（自定义图标）。
- 树形数据开启 `rowSelection` 后默认父子联动：勾选父节点联动全部后代，取消任一子节点自动取消祖先；`checkStrictly: true` 可关闭联动。

### Table 单元格合并

- 新增 `onCell(record, index)` / `onHeaderCell(column)`，返回 `{ colSpan, rowSpan, className, style, ...事件 }` 实现**按行动态合并**；`colSpan` 或 `rowSpan` 为 `0` 表示该单元格已被相邻单元格合并、不渲染。
- 列级静态 `colSpan` 明确为**表头合并**语义（对齐 antd），`0` 时不渲染该表头；移除静态 `rowSpan`（对每一行生效在 HTML 表格中必然错乱，属无效 API）。

### Table 排序能力补齐

- `sortOrder` 受控：设置后该列排序状态完全由 props 决定，点击仅触发 `onChange`（回调携带点击后的意图方向）。
- `defaultSortOrder` 首次渲染默认排序；`sortDirections` 自定义点击方向循环序列（默认 `['ascend', 'descend', null]`）。
- `sorter` 支持 `{ compare, multiple }` 对象形式，`multiple` 声明多列排序；`showSorterTooltip` 以原生 `title` 呈现排序提示。

### Table 分页 / 行选择 / 筛选补齐

- 分页透传：`defaultCurrent`、`defaultPageSize`、`size`、`simple`、`disabled`、`hideOnSinglePage`、`position`（支持置顶/置底与左中右对齐）、`onShowSizeChange`。
- 行选择：新增 `defaultSelectedRowKeys`、`columnWidth`、`columnTitle`、`fixed`（选择列固定左侧）、`hideSelectAll`、`preserveSelectedRowKeys`（行移出 dataSource 后保留选中并缓存行数据）。
- 筛选：`defaultFilteredValue` 默认筛选值；`filterDropdown` 自定义筛选面板（提供 `setSelectedKeys` / `confirm` / `clearFilters`）；`filterIcon` 自定义筛选图标。

### Table 吸顶表头 / 吸底滚动条 / 固定列阴影

- `sticky` 开启时表头拆分为独立 `table`（位于横向滚动容器之外），可吸附外层滚动容器或页面；`getContainer` 指定基准滚动容器，`offsetHeader` 调整吸顶偏移。
- `sticky.offsetScroll`：表格横向溢出且真实滚动条滚出可视区域时，在容器/视口底部吸附一条**可拖拽**的横向滚动条，拖拽与表体滚动双向同步。
- 固定列阴影（ping）：横向滚动时按滚动位置显示/隐藏左右固定列阴影。

### Table 其他

- `locale` prop 真正接入：与全局语言包合并，支持组件级覆盖 `emptyText` / 筛选文案 / 展开收起 aria-label / 排序提示等全量 `TableLocale`。
- `scroll.scrollToFirstRowOnChange` 生效（分页/排序/筛选变化后滚动回表格顶部）；列级 `className` 应用到表头与单元格。
- 根导出补齐表格类型：`TablePaginationConfig` / `TableRowSelection` / `ExpandableConfig` / `SorterResult` / `FilterValue` / `TableLocale` 等。

## 🐛 问题修复

- **行选择无法取消勾选**：`Checkbox` / `Radio` 的 `change` 事件载荷为事件对象（`{ target: { checked } }`），Table 误当布尔值使用导致永远为 truthy，取消单行勾选与取消全选从未生效；改为读取 `e.target.checked`。
- **`onChange` 单次操作触发两次**：`emit('change')` 已会调用 `onChange` prop，叠加显式 `props.onChange?.()` 导致重复触发；移除冗余调用（分页/排序/筛选三处）。
- **固定列滚动时透出下层内容**：固定列表头与行 hover 态使用半透明填充色（`rgba(0,0,0,0.02)`）作背景，横向滚动时下层内容透出；改为半透明色叠加在不透明底色之上。
- **吸顶表头无法吸附外层容器**：`overflow-x: auto` 的滚动容器同时成为纵向滚动容器，`position: sticky` 被限制在容器内部；表头拆分后结构性解决，且拆分的两个 `table` 通过 `colgroup` + `table-layout: fixed` 保证列宽对齐。
- **仅提供 `filterDropdown` 的列不渲染筛选入口**：改为 `filters` 或 `filterDropdown` 任一存在即渲染（对齐 antd）。
- **列级 `colSpan` 同时作用于数据单元格**导致表格结构错乱：收敛为表头合并语义（见新增功能）。
