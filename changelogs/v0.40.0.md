# v0.40.0 (2026-08-11)

## 🎯 核心变更

### 新增交互式语义化 DOM 预览（对齐 Ant Design v6 SemanticPreview）

参照 `ant-design/.dumi/theme/common/SemanticPreview.tsx` 移植到 Vue，替代原先纯静态的「DOM 结构与 className 映射」代码块。

**能力**：

- 鼠标移到右侧节点列表任一项，左侧预览区自动框出对应 DOM 元素（多个匹配时首个为主标记）
- 图钉按钮可固定高亮，移开鼠标仍保持
- 信息图标弹出该节点的 Vue 用法示例（Prism 高亮）
- 高亮框坐标基于 `getBoundingClientRect()` 实测，随 `resize` / `ResizeObserver` 自动重算

**实现要点**：

- React `cloneElement` 在 Vue 无对应能力，改用**作用域插槽**把标记 `classNames` 下发给使用方
- 标记类固定不随激活项变化，hover 时演示组件不重渲染，避免动画被打断
- 插槽 prop 键名不做 kebab→camel 归一化，`<slot :classNames="...">` 必须与使用方解构名逐字一致
- 弹层被 Trigger 传送到 `body`，代码块样式必须写在非 scoped 块中

### Button 补齐 `content` 语义节点

对齐 Ant Design v6 的 `root` / `icon` / `content` 三节点结构，文本内容包入 `<span class="hmfw-btn-content">`。无子节点时（纯图标按钮）不渲染该节点，`hmfw-btn-icon-only` 行为不变。

未给 `.hmfw-btn-content` 添加任何视觉样式——纯挂载钩子，根元素已负责 flex 居中，加规则有布局回归风险。两个中文字的内层 `hmfw-btn-two-chinese-chars-content` 未改动，既有 CSS 与 6 条断言依赖它。

### 修复 loading 图标不旋转

**根本原因**：`@hmfw/icons` 使用 `inheritAttrs: false` 且在 `class` **之后**展开 `...attrs`，组件传入的 `class` 会整体顶掉包内的 `anticon` 基类，连同包内运行时注入的 `.anticon-spin` 动画一起失效；而本库从未定义过 `.hmfw-icon-spin` 规则，导致 Button / Select / message 的加载图标全部静止。

**解决方案**：新增 `components/_internal/icon/style/index.css` 自带 keyframes，不依赖图标包的运行时注入，同时兜住 `.hmfw-icon-spin` 与 `.hmfw-icon-loading`。必须通过 `@import` 接入 `components/style.css`——`tsup.config.ts` 只正则扫描 `@import './...'` 行，裸规则进不了 `dist/style.css`。顺带删除 `input/style/index.css` 中重复的那份动画定义。

### 修正跨组件失效的 `hmfw-button` 类名

多处文档与 Demo 写的是从未存在过的 `hmfw-button-*`（实际前缀为 `hmfw-btn`，Button 内部 `usePrefixCls('btn')`），其中 `EmptyClassNames.vue` 的两条是完全命不中的死 CSS。全部改正并核对真实渲染输出。
