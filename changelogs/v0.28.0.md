# v0.28.0

发布日期：2026-07-26

## 🔧 重构

### Radio

- **direction 属性**：RadioGroup 新增 `direction`（horizontal/vertical），补全对应 CSS 布局样式
- **类型约束强化**：Radio / RadioButton / RadioGroup 全部采用 `satisfies Record<keyof XProps, any>` 模式，杜绝双源头漂移
- **RadioButton 独立实现**：拆分为独立组件并支持 `classNames`/`styles` 语义化 API
- **语义化 API**：RadioGroup 新增 `classNames`/`styles` 支持
- **事件对齐 AntD v6**：`RadioChangeEvent` 补充 `stopPropagation`/`preventDefault` 方法
- **测试与文档**：新增 7 个测试用例并更新文档

### RangePicker

- **类型约束强化**：使用 `satisfies Record<keyof RangePickerProps, any>` 强制 props 与接口一致
- **共享工具抽取**：将 9 个日期处理函数（`pad`/`formatDate`/`parseDate`/`isSameDay` 等）抽取到 `components/_utils/date.ts` 共享模块，减少代码重复
- **国际化修复**：面板标题按 locale 动态格式化（zh-CN：`2024年 1月`，en-US：`January 2024`），修复硬编码问题
- **API 一致性**：移除未实现的 `allowEmpty` 属性，补充 `disabledDate` 参数文档说明

### Rate

- **类型约束强化**：添加 Props `satisfies` 约束，防止类型漂移
- **事件类型导出**：补充并导出 4 个事件类型定义（`RateChangeHandler` 等）
- **Demo 补充**：新增 `RateText.vue` 演示文案展现场景
- **文档修正**：修正 `size` 默认值说明，优化 `RateCharacterRenderContext.isHalf` 注释

## 📊 质量提升

本次重构覆盖 **3 个组件**，延续系统性代码质量提升：

- ✅ **类型安全**：全部组件采用 `satisfies Record<keyof XProps, any>` 模式，确保运行时 props 与 TypeScript 接口完全一致
- ✅ **代码复用**：日期处理逻辑抽取为共享工具模块
- ✅ **国际化**：修复面板标题硬编码，支持中英文动态格式化
- ✅ **对齐 AntD v6**：补齐 `direction`、事件方法与语义化 API
