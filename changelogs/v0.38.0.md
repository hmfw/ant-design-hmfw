# v0.38.0 (2026-08-10)

ColorPicker 组件全面审查修复。本次修复覆盖代码质量、交互正确性、样式 Token 化、无障碍与 Demo 覆盖五个维度，其中**组件级 Token 作用域修正**属于用户可见的显示缺陷修复。

## 🐛 Bug 修复

### 面板组件级 Token 在 Teleport 后无法解析（显示缺陷）

面板由 Trigger 通过 Teleport 挂载到 `document.body`，不在 `.hmfw-color-picker` 子树内。CSS 自定义属性沿 DOM 树继承，因此定义在触发器根节点上的 12 个面板 Token 全部解析失败。

其中 `--hmfw-color-picker-sb-height` 失效后 `height` 回退为 `auto`，而饱和度/明度画布的子元素（白/黑渐变层、游标）均为绝对定位，导致**取色区高度塌陷为 0，面板不可用**。

修正方式：按消费位置分两处定义 Token —— 触发器 Token（3 个）定义在 `.hmfw-color-picker`，面板 Token（12 个）定义在 `.hmfw-color-picker-panel`。与仓库既有约定一致（Trigger 将 `--hmfw-trigger-arrow-*` 定义在 `.hmfw-trigger-popup` 上）。

### 面板容器类名重复

`<Trigger>` 的 `popupClass` / `popupStyle` 与内层面板 div 同时施加 `hmfw-color-picker-panel` 类，导致外层定位容器与内层面板重复应用 `padding` / `width` / 背景等样式。移除 Trigger 侧传参，类名与自定义样式仅作用于内层面板。

### 灰色区拖拽色相跳变

饱和度为 0 时色相被归零，再次拖动会出现颜色突变。分离出显示用色相 `hueDisplay`，仅在 `s > 0` 时同步，色相滑块位置与画布底色保持稳定。

### 其他修复

- **全局监听器堆积**：拖拽的 `mousemove` / `mouseup` 改为按需注册、松手即摘除；新增 `onBeforeUnmount` 兜底，避免拖拽中被卸载时监听器残留
- **色相滑块缺少触摸支持**：补齐 `touchstart` / `touchmove` / `touchend`，与饱和度画布行为一致
- **清除后状态残留**：`clearColor()` 同步重置内部 HSB 与显示色相

## ✨ 改进

### 样式全面 Token 化

`font-size` / `border-radius` / `padding` / `gap` / `min-height` / `transition` 等硬编码值全部替换为 `var(--hmfw-*)`。HSV 画布渐变、色相环渐变、游标描边与阴影按设计意图保持固定值并注明原因（跟随主题反色会破坏取色准确性或使游标不可见）。

### 无障碍

- 清除按钮补齐 `role="button"` / `aria-label` / `tabindex`，支持 Enter 与 Space 键触发
- 禁用态触发器补齐 `aria-disabled`

### 类型与规范

- props 改用 `satisfies Record<keyof ColorPickerProps, any>` 约束，杜绝运行时 props 与 TS 接口双源头漂移
- 新增导出事件处理器类型：`ColorPickerChangeHandler` / `ColorPickerClearHandler` / `ColorPickerOpenChangeHandler`

### 文档

- `format` 说明改为如实描述：**当前仅实现 `hex`**，传入 `rgb` / `hsb` 暂无效果（面板始终渲染 HEX 输入框）
- 设计 Token 章节拆分为全局 Token（21 项）与组件 Token（触发器 3 项 / 面板 12 项），说明 Teleport 对覆盖位置的影响，并给出可用的 `:global()` 覆盖示例

## 📝 Demo

新增 3 个示例：三种尺寸、禁用状态、清除颜色。

## ✅ 测试

- 单元测试 12 → 17：面板类名唯一性、`format` 标签如实性、`allowClear` 事件与无障碍属性、`aria-disabled` 存在性
- E2E 测试 5 → 9：新增面板组件级 Token 在 Teleport 后可解析的回归测试；定位策略改为按 DemoBlock 标题作用域查找，不再依赖页面上组件的绝对序号
- 修复面板位置断言的偶发失败：两个 `boundingBox()` 分别测量时，期间页面滚动会导致视口相对坐标错位，改为单次 `page.evaluate()` 原子测量

全体 2494 单元测试通过，类型检查通过，ColorPicker E2E 9/9 通过。
