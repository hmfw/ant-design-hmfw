# v0.48.0 (2026-08-17)

## ✨ 新增功能

### 新增 Masonry 瀑布流组件

新增 **Masonry** 瀑布流布局组件，用于展示不同高度的内容。组件总数达到 **68 个**。

**核心特性**：

- **自动瀑布流布局**：通过贪心算法将每个项目放置在当前最短的列中，实现视觉上的平衡和美观
- **响应式列数**：支持 7 个断点配置（xxxl/xxl/xl/lg/md/sm/xs），可根据屏幕宽度自动调整列数
- **灵活间距配置**：支持单值或 `[水平间距, 垂直间距]` 数组配置
- **RTL 布局支持**：自动适配从右到左的语言布局
- **fresh 模式**：持续监听子项尺寸变化并自动重新布局（适用于图片加载等场景）
- **布局变化回调**：通过 `onLayoutChange` 获取项目排序信息
- **预指定列功能**：支持通过 `item.column` 预先指定某些项目的列位置
- **语义化 API**：支持 `classNames` 和 `styles` 对容器和项目进行细粒度样式控制

**API 设计**：

```typescript
interface MasonryProps {
  items?: MasonryItemType[]
  columns?: number | Partial<Record<Breakpoint, number>>
  gutter?: number | [number, number]
  fresh?: boolean
  prefixCls?: string
  className?: string
  style?: CSSProperties
  classNames?: MasonryClassNames
  styles?: MasonryStyles
  onLayoutChange?: (sortInfo: { key: string | number; column: number }[]) => void
}

interface MasonryItemType<T = any> {
  key: string | number
  data: T
  column?: number
  height?: number
}

interface MasonryClassNames {
  root?: string
  item?: string
}

interface MasonryStyles {
  root?: CSSProperties
  item?: CSSProperties
}
```

**使用示例**：

```vue
<template>
  <!-- 基础用法 -->
  <Masonry :columns="4" :gutter="16" :items="items">
    <template #default="{ item, index }">
      <Card>{{ item }}</Card>
    </template>
  </Masonry>

  <!-- 响应式列数 -->
  <Masonry :columns="{ xs: 1, sm: 2, md: 3, lg: 4, xl: 5 }" :gutter="[16, 24]" :items="items">
    <template #default="{ item }">
      <Card>{{ item }}</Card>
    </template>
  </Masonry>

  <!-- 图片瀑布流 -->
  <Masonry :columns="4" :gutter="16" :items="imageItems" fresh>
    <template #default="{ item }">
      <img :src="item" style="width: 100%; display: block" />
    </template>
  </Masonry>

  <!-- 监听布局变化 -->
  <Masonry :columns="4" :items="items" @layout-change="handleLayoutChange">
    <template #default="{ item }">
      <Card>{{ item }}</Card>
    </template>
  </Masonry>
</template>

<script setup lang="ts">
import { Masonry, Card } from '@hmfw/ant-design'
import type { MasonryItemType } from '@hmfw/ant-design'

const items: MasonryItemType<string>[] = [
  { key: 'item-1', data: 'Content 1' },
  { key: 'item-2', data: 'Content 2' },
  { key: 'item-3', data: 'Content 3' },
]

const handleLayoutChange = (sortInfo) => {
  console.log('布局已更新：', sortInfo)
}
</script>
```

**技术实现**：

- **布局算法**：`usePositions` hook 实现贪心算法，维护每列的当前高度，新项目总是放入最短列
- **尺寸监听**：使用 ResizeObserver 监听容器和子项尺寸变化，支持环境兼容性检测
- **性能优化**：
  - 使用浅比较替代 JSON.stringify 进行变更检测
  - 使用 computed 替代 ref + watchEffect 减少响应式开销
  - 样式计算变量复用，减少重复字符串拼接
  - requestAnimationFrame 延迟批量更新，避免频繁重排
- **响应式设计**：复用 Grid 的 `useBreakpoint` hook，共享全局 matchMedia 监听器
