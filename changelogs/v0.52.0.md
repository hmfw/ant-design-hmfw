# v0.52.0 (2026-10-02)

## ✨ 新增功能

### Input 新增 `addonBefore` / `addonAfter` 前/后置标签

基础 `Input` 新增 `addonBefore` / `addonAfter` 属性（及同名插槽），用于在输入框前后拼接标签单元，可放文本、图标，或嵌入 `Select` / `Button` 等组件，对齐 Ant Design 的 input group 结构。

- 新增 group DOM：`span.hmfw-input-group-wrapper > span.hmfw-input-group > [addon] + 核心元素 + [addon]`，裸输入框与带前后缀的 affix-wrapper 两种形态均通过同一包装器接入
- 相邻边框合并（`margin-left: -1px` + 圆角合并），focus/focus-within 时 `z-index` 抬升保证高亮边框不被相邻标签遮挡，与既有 `search-with-button` 分组同款做法
- `size`（`large` / `small`）、校验状态（`error` / `warning`）、禁用态修饰类统一挂在 group-wrapper 上
- 嵌入 `Select` / `Button` 自动去除自身边框 / 背景 / 阴影（含 `:hover`、`.hmfw-select-open` 态），由标签单元统一呈现
- 语义化 API 新增 `groupWrapper` / `addon` 两个节点（`classNames` / `styles` 均支持）

### InputSearch / InputPassword 重构为委托基础 Input，补齐 affix 全家桶

`InputSearch` 与 `InputPassword` 由独立 `<input>` 实现改为**封装基础 `Input`**（对齐 AntD 架构），由此天然继承 `prefix` / `suffix` / `allowClear` / `showCount` / `maxLength` / `classNames` / `styles` 等能力，消除重复实现：

- `InputPassword` 的显隐切换图标与用户 `suffix` 组合后交由 Input 渲染，保留 `visibilityToggle` / `iconRender` / `action`（click/hover）
- `InputSearch` 无 `enterButton` 时搜索图标作为可点击 suffix；有 `enterButton` 时渲染「Input + 尾随 Button」分组，回车 / 点击按钮 / 清空分别触发 `search` 并带 `source`
- 两者均转发内部 Input 的 `focus` / `blur` / `input` expose

## 🐛 问题修复

- **Search / Password 传 `prefix` 崩溃**：此前给 `Input.Search` / `Input.Password` 传 `:prefix` 会抛 `TypeError: Cannot set property prefix of #<Element> which has only a getter`（未声明的 prop 落入 attrs 被当作只读 DOM property 设到根节点）。委托基础 Input 后该类崩溃从结构上根除
- **Select 作为 addon 时左侧双边框**：Select 的边框 / 背景在根元素 `.hmfw-select` 上而非 `.hmfw-select-selector`，此前仅中和了 selector 导致 Select 根保留边框、与标签单元叠出双边框；现将边框 / 背景 / 阴影中和下移到 `.hmfw-select` 根并覆盖 `:hover` / `.hmfw-select-open` 态
