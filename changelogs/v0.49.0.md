# v0.49.0 (2026-08-17)

## ✨ 新增功能

### 新增 Splitter 分割面板组件

新增 **Splitter** 分割面板组件，用于将页面或容器自由切分为多个可调整大小的区域。组件总数达到 **69 个**。

**核心特性**：

- **水平/垂直分割**：支持 `orientation` 与 `vertical` 简写属性，可自由组合
- **灵活的尺寸控制**：每个面板支持受控 `size` 与非受控 `defaultSize`，支持像素值与百分比，`min`/`max` 约束拖拽范围
- **折叠面板**：`collapsible` 支持布尔值（两侧可折叠）或对象精确控制 `start`/`end` 折叠方向；`showCollapsibleIcon` 三态（`true` 常显 / `false` 隐藏 / `'auto'` 悬停显示，默认）
- **懒加载拖拽模式**：`lazy` 开启后拖拽时仅显示预览线，松开后才应用新尺寸，适合内容重渲染场景
- **折叠动画**：`collapsible.motion` 启用面板折叠过渡动画
- **自定义图标**：`draggerIcon` 自定义拖拽图标，`collapsible.icon` 自定义折叠图标
- **完整事件体系**：`onResizeStart` / `onResize` / `onResizeEnd` / `onCollapse` 拖拽全生命周期回调，`onDraggerDoubleClick` 双击拖拽条
- **内容销毁**：`destroyOnHidden` 折叠时销毁面板内容，可全局设置并在单个面板覆盖
- **语义化 API**：支持 `classNames` 和 `styles` 对根节点、面板、拖拽条（含 default/active 状态）进行细粒度样式控制
- **无障碍支持**：拖拽条 `role="separator"` + `aria-valuenow/min/max`，折叠按钮 `role="button"` + 键盘 Enter/Space 操作
- **设计 Token 化**：组件级 Token `--hmfw-splitter-bar-size` / `--hmfw-splitter-trigger-size` / `--hmfw-splitter-bar-draggable-size`，派生规则对齐 Ant Design v6 `prepareComponentToken`

**API 设计**：

```typescript
interface SplitterProps {
  orientation?: 'horizontal' | 'vertical'
  vertical?: boolean
  rootClassName?: string
  collapsible?: { motion?: boolean; icon?: { start?: VNode; end?: VNode } }
  destroyOnHidden?: boolean
  draggerIcon?: VNode
  lazy?: boolean
  classNames?: SplitterClassNames
  styles?: SplitterStyles
  onDraggerDoubleClick?: (index: number) => void
  onResizeStart?: (sizes: number[]) => void
  onResize?: (sizes: number[]) => void
  onResizeEnd?: (sizes: number[]) => void
  onCollapse?: (collapsed: boolean[], sizes: number[]) => void
}

interface PanelProps {
  className?: string
  style?: CSSProperties
  min?: number | string
  max?: number | string
  size?: number | string
  collapsible?: boolean | { start?: boolean; end?: boolean; showCollapsibleIcon?: boolean | 'auto' }
  resizable?: boolean
  defaultSize?: number | string
  destroyOnHidden?: boolean
}
```
