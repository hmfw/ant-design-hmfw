# v0.53.1 (2026-10-16)

本次为 Select 空值重置与 Form 初始值快照的补丁修复版本。

## 🐛 问题修复

- **Select 重置为 `undefined` 后仍显示旧值**：`value` 从有效值变为 `undefined` 时，组件此前会从受控模式切换到非受控模式，但 `innerValue` 因守卫条件未被清空，导致继续显示旧选中文本。现同步包括 `undefined` 在内的所有外部值变化，单选重置为空值、多选重置为空数组后均正确显示占位符。
- **Form 无法重置初始值为 `undefined` 的字段**：Form 挂载时直接对 Vue 响应式 Proxy 调用 `structuredClone` 会失败，降级到 JSON 克隆后又会丢失值为 `undefined` 的字段，导致无参数 `resetFields()` 遗漏这些字段。现先通过 `toRaw` 解除 Proxy，再创建保留 `undefined` 字段的初始值快照。

## 📝 文档 / 测试

- Form「复杂控件绑定」Demo 新增重置按钮：选择城市后点击重置，可直接验证初始值为 `undefined` 的 Select 恢复为空并显示占位符。
- Select 新增单选、多选从有效值变为 `undefined` 的组件级回归测试。
- Form 新增 `resetFields()` 将 Select 恢复为 `undefined` 的集成测试。

验证：全量单测 2673 个通过；`typecheck`、ESLint、Prettier、文档构建通过。
