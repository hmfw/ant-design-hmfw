# v0.50.0 (2026-08-29)

## ✨ 新增功能

### DatePicker 新增 week 周选择模式

`picker` 属性新增 `'week'` 模式，选择一周（周日为一周起始），值格式为 `'YYYY-ww'`（年内周数，如 `'2026-21'`）。

- 面板仍渲染日期网格，点击任一天选中该天所在整周，整周 7 天统一高亮（`hmfw-date-picker-day-week-selected`）
- 值取所选日期所在周的周日；默认格式 `'YYYY-ww'`，占位符使用语言包新增的 `weekPlaceholder`（中文「请选择周」/ 英文「Select week」）
- `_utils/date.ts` 新增 `getWeekNumber` / `weekStart` / `isSameWeek` / `parseWeek`（支持 `'2026-21'` 与 `'2026-W21'` 两种写法，与 `getWeekNumber` 互逆），`formatDate` 新增 `ww` / `w` token

### DatePicker 新增 placement / variant 属性

- `placement`: 弹层弹出位置（`'bottomLeft' | 'bottomRight' | 'topLeft' | 'topRight'`，默认 `'bottomLeft'`），与 TimePicker 对齐
- `variant`: 形态变体（`'outlined' | 'borderless' | 'filled' | 'underlined'`，默认 `'outlined'`），由共享 PickerInput 渲染

### RangePicker 新增 variant 属性

支持与 DatePicker / TimePicker 一致的 `variant` 形态变体。

### TimePicker 面板新增「此刻」/「确定」按钮

- 语言包 `TimePicker` 新增 `now`（中文「此刻」/ 英文「Now」）与 `ok`（中文「确定」/ 英文「OK」）文案
- `showNow` 开启时面板底部渲染「此刻」按钮：`needConfirm` 模式下将当前时间写入暂存值待确认，否则立即生效并提交
- `needConfirm` 开启时渲染「确定」按钮，点击提交暂存值

### DatePicker / TimePicker 新增 focus / blur 事件

- 两个组件均新增 `focus`、`blur` 事件，在输入框获得/失去焦点时触发
- 通过共享 PickerInput `expose` 的内置输入框实现 `focus()` / `blur()` 实例方法调用支持

### 类型导出完善

- **DatePicker**: 公开导出事件回调类型 `DatePickerUpdateHandler` / `DatePickerChangeHandler` / `DatePickerOpenChangeHandler` / `DatePickerPanelChangeHandler` / `DatePickerFocusHandler` / `DatePickerBlurHandler`，以及 `DatePickerPanelMode`、`ShowTimeConfig`、`CellRender` / `CellRenderInfo` / `CellRenderType`
- **RangePicker**: 公开导出 `RangeDateValue`、`RangePickerUpdateHandler` / `RangePickerChangeHandler` / `RangePickerOpenChangeHandler` / `RangePickerCalendarChangeHandler`
- **TimePicker**: 公开导出 `TimePickerFocusHandler` / `TimePickerBlurHandler`

### 新增 6 个演示

- **DatePicker**: 尺寸/状态/形态变体（`DatePickerSize`）、自定义日期格式（`DatePickerFormat`）、定制单元格（`DatePickerCellRender`）、额外的页脚（`DatePickerExtraFooter`）
- **RangePicker**: 排序与分隔符（`RangePickerOrder`）
- **TimePicker**: 12 小时制（`TimePickerUse12Hours`）

## 🔨 代码重构

### 新增共享内部组件 PickerInput

`components/_internal/picker-input/`：DatePicker / TimePicker / RangePicker 三组件统一输入触发器，渲染根容器 + 输入区 + 后缀图标 + 清除按钮，输出独立的 `hmfw-picker-root / input / suffix / clear / disabled / small / large / status-* / variant-*` 共享类体系。

- 单输入框（DatePicker / TimePicker）由组件内置渲染；多输入框（RangePicker）通过 default 插槽覆盖输入区
- 各组件根类（`hmfw-date-picker` 等，承载宽度等组件自身规则）由调用方通过 `classNames.root` 传入，保留历史类名兼容
- 三组件触发器样式（边框、hover、open 态、状态色、清除按钮、变体）大瘦身，统一收拢至共享 CSS

### 新增共享内部组件 TimeColumn

`components/_internal/time-column/`：TimePicker 与 DatePicker（showTime）共用的时间选择列，内置选中定位滚动（首挂载立即定位 + 值变化平滑滚动，RAF 节流 + 值缓存避免重复滚动）。

- 输出「共享基础类 + 调用方前缀类」双类名：基础类 `hmfw-picker-time-column / hmfw-picker-time-cell` 承载视觉样式，前缀类（如 `hmfw-time-picker-panel-cell`）保留各组件历史类名，兼容既有自定义样式与测试断言

### 新增 `_utils/time.ts` 时间工具

`parseTime` / `formatTime` / `hasSeconds` / `generateTimeOptions` 由 TimePicker 内部提取为共享工具，DatePicker（showTime）与 TimePicker 共同使用。

### 其他优化

- **CellRender 类型迁移**: `CellRender` / `CellRenderInfo` 类型定义由 calendar 移至 date-picker（AntD 中 `cellRender` 源于 DatePicker API），calendar re-export 并新增 `CalendarCellRenderInfo` 别名保持兼容；`CellRenderType` 新增 `'quarter' | 'week'` 值
- **DatePicker props 规范化**: props 定义改用 `satisfies Record<keyof DatePickerProps, any>` 模式强制与类型接口同步；`disabledDate` 回调新增 info 参数 `{ from, type }`
- **Select**: 清除按钮 hover 背景 token 由 `--ant-color-bg-base` 修正为 `--hmfw-color-bg-container`
- **Calendar**: 清理样式注释代码，`--ant-motion-duration-slow` 前缀修正为 `--hmfw-motion-duration-slow`，mini 模式字号改用 `--hmfw-font-size-sm` token
