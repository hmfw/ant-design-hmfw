# v0.33.0 (2026-08-02)

## 国际化全面接线与 Bug 修复

本次更新将原先声明但未消费的语言包文案全部接入了对应组件，并新增 Alert / Form / Slider / Carousel 四个语言包段落。同时修复了 Popconfirm 英文模式字间距残留和 Modal.confirm 独立挂载时 locale 丢失的问题。

---

## ✨ 新增语言包段落

### Alert

- `Alert.close`：关闭按钮 aria-label 文案（中文：`关闭`，英文：`Close`）

### Form

- `Form.required`、`Form.min`、`Form.max`、`Form.pattern`、`Form.email`、`Form.validateFailed`：校验缺省文案

### Slider

- `Slider.min`、`Slider.max`、`Slider.handle`：滑块手柄 aria-label 文案

### Carousel

- `Carousel.label`、`Carousel.prev`、`Carousel.next`、`Carousel.slide`、`Carousel.goTo`：走马灯导航 aria-label 文案

### DatePicker 格式化函数

- `DatePicker.yearFormat(year)`：年份显示格式（中文 `${year}年`，英文 `String(year)`）
- `DatePicker.monthYearFormat(monthLabel, year)`：面板头部「年 + 月」组合顺序（中文 `${year}年 ${monthLabel}`，英文 `${monthLabel} ${year}`）
- `DatePicker.firstDayOfWeek`：一周起始日配置（当前中英文均为 `0`，为未来周一起始预留）

### Pagination

- `Pagination.navLabel`、`Pagination.pageLabel(page)`：分页导航及页码 aria-label

## 🔧 组件接线

### Pagination

- 全 10 个 locale key 接线：上下页/快翻 aria-label、`跳至`/`页` 文本、`条/页` 选项标签

- close aria-label 从硬编码 `关闭` → `locale.Alert.close`

### Form 校验

- `runRules` 逐条校验缺省文案 → `locale.Form.*`

## 🐛 Bug 修复

### Modal.confirm 英文模式下按钮仍显示中文

- **根因**：`Modal.confirm()` 通过 `createApp()` 独立挂载，脱离 ConfigProvider 的 provide/inject 链，`ConfirmDialog` 中 `useLocale()` 永远拿到默认 `zhCN`
- **修复**：`ModalFuncProps` 新增 `locale` 字段；`ConfirmDialog` 优先使用 `config.locale`，再回退 inject 的值

### Popconfirm 中英文切换后按钮字间距残留

- **根因**：`hasTwoCNChar` computed 直接读 `buttonRef.value.textContent`（原生 DOM 属性），Vue 响应式系统不追踪。locale 从 zh→en 切换后按钮文字变化，但 computed 不重新求值，`hmfw-btn-two-chinese-chars` class 残留
- **修复**：引入 `slotText` ref 作为文字内容的响应式镜像，通过 `onUpdated` 在每次组件更新后同步；computed 同时依赖 `slotText.value` 和 DOM textContent 回退，保证首帧正确且后续变化可追踪
