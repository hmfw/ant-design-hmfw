# v0.51.1 (2026-10-02)

## 🐛 问题修复

### 为 Transition / TransitionGroup 子节点改用函数插槽

内置 `Transition` / `TransitionGroup` 是有状态组件，Vue 要求其默认插槽为函数。此前多处将条件 VNode（`open && <ul>`）或数组（`list.map(...)`）直接作为子节点传入，开发模式下触发 `normalizeVNodeSlots` 告警「Non-function value encountered for default slot」。运行时 Vue 会自动把它包成函数，功能正常，告警在生产构建中也会被剥除，故本次为纯写法规范修复，无运行时行为变更。

统一改为函数插槽（`{() => cond ? <...> : null}`），涉及：

- **Menu / SubMenu**: inline 展开动画与顶部溢出菜单的折叠动画
- **Drawer**: 抽屉显隐动画
- **Collapse**: 面板展开动画
- **Image**: 预览浮层淡入淡出
- **Modal**: 对话框缩放动画
- **FloatButton**: 回到顶部按钮淡入淡出、悬浮按钮组展开动画
- **Upload**: 文件列表 `TransitionGroup` 的列表项渲染
