# v0.52.1 (2026-10-02)

## 🐛 问题修复

### Dropdown `menu.onClick` 单次点击触发两次

此前给 `Dropdown` 的 `menu` 配置传 `onClick`（及 `onSelect` / `onDeselect` / `onOpenChange`）时，单次点击菜单项会触发**两次**回调。

- **根因**：`renderOverlay` 用 `<Menu {...props.menu} onClick={handleMenuClick} />` 渲染菜单，`props.menu` 自带的用户 `onClick` 与显式 `onClick` 同时存在时，Vue 的 `mergeProps` 会把两个事件监听器合并成数组 `[menu.onClick, handleMenuClick]`；`Menu` 触发 `click` 事件时数组内两个监听器均执行，而 `handleMenuClick` 内部又再次调用了 `menu.onClick`，叠加导致重复触发。
- **修复**：在展开前将 Dropdown 专有回调（`onClick` / `onSelect` / `onDeselect` / `onOpenChange`）从 `props.menu` 中剥离，统一由 Dropdown 显式接线到 `Menu`，不再随 `{...props.menu}` 泄漏进 Vue prop 系统（与 `types.ts` 中 `DropdownMenuConfig` 的既有设计注释一致）。

## 📝 文档 / 测试

- 收紧单测：`calls menu.onClick when menu item is clicked` 由 `toHaveBeenCalled()` 改为 `toHaveBeenCalledTimes(1)`，防止重复触发回归（旧断言正是因此漏过该 bug）。

验证：`typecheck` 通过；`test Dropdown`（49 单测全通过）。
