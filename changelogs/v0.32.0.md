# v0.32.0 (2026-08-02)

## Tour 组件全面优化与功能增强

本次更新对 Tour 漫游引导组件进行了全面优化，新增多项实用功能，修复已知缺陷，提升用户体验和开发体验。

---

## ✨ 新增功能

### 键盘快捷键支持

- **keyboard** 属性：支持通过键盘快捷键操作引导流程
  - `Esc` 键：关闭引导
  - `←` 键：上一步
  - `→` 键：下一步
  - 默认开启，可通过 `keyboard={false}` 禁用

```vue
<Tour :steps="steps" :keyboard="true" />
```

### 自定义挂载容器

- **getPopupContainer** 属性：支持自定义 Tour 组件的挂载节点
  - 默认挂载到 `document.body`
  - 可指定任意 DOM 容器，适应复杂布局场景

```vue
<Tour :steps="steps" :get-popup-container="() => document.getElementById('app')" />
```

### HTMLElement 直接传入

- **target** 属性类型扩展：现支持三种方式指定目标元素
  - CSS 选择器字符串：`target: '#my-button'`
  - 函数返回元素：`target: () => buttonRef.value`
  - **新增**：直接传入 HTMLElement：`target: buttonRef.value`

```vue
<template>
  <Button ref="buttonRef">点击</Button>
  <Tour :steps="[{ target: buttonRef }]" />
</template>
```

### 国际化支持

- **接入项目国际化系统**：按钮文本支持多语言切换
  - 中文：上一步 / 下一步 / 完成
  - 英文：Previous / Next / Finish
  - 可通过 `ConfigProvider` 全局配置或 `nextButtonProps.children` / `prevButtonProps.children` 自定义

```vue
<ConfigProvider :locale="zhCN">
  <Tour :steps="steps" />
</ConfigProvider>
```

### 类型定义导出

- **事件类型导出**：新增三个事件处理函数类型定义
  - `TourChangeHandler`: `(current: number) => void`
  - `TourCloseHandler`: `() => void`
  - `TourFinishHandler`: `() => void`

```typescript
import type { TourChangeHandler } from '@hmfw/ant-design'

const handleChange: TourChangeHandler = (current) => {
  console.log('当前步骤:', current)
}
```

## 🐛 缺陷修复

### SVG mask ID 冲突

- **问题**：硬编码的 `'tour-mask'` ID 导致多个 Tour 实例同时存在时产生冲突
- **修复**：改为动态生成唯一 ID `tour-mask-${random}`
- **影响**：支持页面内同时渲染多个 Tour 组件

### gap.offset 数组处理

- **问题**：`gap.offset: [x, y]` 数组形式未正确区分水平/垂直方向
- **修复**：根据 `placement` 判断方向
  - 水平方向（left/right）：使用 `offset[0]`
  - 垂直方向（top/bottom/其他）：使用 `offset[1]`
- **影响**：`gap.offset` 数组形式现在能正确控制不同方向的间距

### 滚动行为优化

- **问题**：`scrollIntoViewOptions` 默认 `block: 'center'` 导致页面大幅滚动
- **优化**：改为 `block: 'nearest'`
- **影响**：减少不必要的页面跳动，提升用户体验
