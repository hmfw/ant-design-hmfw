# v0.39.0 (2026-08-11)

## 🎯 核心优化

### Anchor 锚点滚动动画体验优化

**问题**：用户反馈点击锚点后滚动动画"先慢后快"，体验不流畅。

**根本原因**：

1. **缓动函数数学特性**：原实现使用 `easeInOutCubic`（与 Ant Design 官方一致），其慢启动特性导致前 100ms 仅完成 4.3% 的滚动距离
2. **CSS 冲突**：文档站全局 `scroll-behavior: smooth` 与 JS 动画产生冲突，进一步降低响应速度

**解决方案**：

1. 改用 `easeOutCubic` 缓动函数：快速启动 + 平滑减速，符合用户对流畅滚动的心理预期
2. 删除文档站全局 `scroll-behavior: smooth`，统一由 JS 控制滚动行为

**性能提升**：

- 前 50ms：2px → 358px（**179倍**）
- 前 100ms：26px (4.3%) → 555px (59.9%)（**21.3倍**）
- 前 150ms：38px → 700px（**18.4倍**）

**动画曲线分析**：

- 50ms：38.7% 快速启动 ✅
- 100ms：59.9% 接近目标
- 150ms：75.6% 开始减速
- 200ms：86.6% 平滑停止

**测试验证**：

- 单元测试：48/48 通过
- E2E 滚动性能测试：前 100ms 达到 59.9%，符合预期
- 新增 E2E 测试：`anchor-scroll-animation.e2e.spec.ts`

**注意**：本优化是对 Ant Design 官方实现的**体验增强**（官方使用 easeInOutCubic，同样存在慢启动问题）。
