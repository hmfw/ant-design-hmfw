# v0.43.0 (2026-08-13)

## 🎯 核心变更

### Divider 全面审查修复

#### 💥 破坏性变更：语义节点重命名 `text` → `content`，新增 `rail`

`DividerClassNames.text` / `DividerStyles.text` 已**移除**，文字容器节点统一改为 `content`，与 Ant Design v6 的 `DividerSemanticType` 完全对齐。同时新增 `rail` 语义节点，可对文字两侧的线条独立定制 class 与 style。

**迁移方式**：将所有 `:class-names="{ text: 'x' }"` / `:styles="{ text: { ... } }"` 中的 `text` 键改为 `content`。

语义节点总览（新）：

| 节点      | 说明                                                   |
| --------- | ------------------------------------------------------ |
| `root`    | 分割线根容器                                           |
| `rail`    | 文字两侧线条（带文字时生效，左右共享同一 class/style） |
| `content` | 分割线中的文字容器（带文字时生效）                     |

#### Props 规范合规

将 `defineComponent` 内联的 props 提取为独立 `dividerProps` 变量，加上 `satisfies Record<keyof DividerProps, any>`，确保 `DividerProps` 接口与运行时 props 编译期强制同步。

#### `orientationMargin` 改用逻辑属性

`textStyle` 中 `marginLeft` / `marginRight` 替换为 `marginInlineStart` / `marginInlineEnd`，与 Ant Design v6 对齐，为 RTL 支持铺路。

#### 新增 `DividerPlain.vue` demo

补充 `plain` prop 的独立演示，完整对比默认标题样式（`font-weight: 500`、`font-size-lg`）与正文样式，覆盖 center / left / right 三种方向。

#### 设计 Token 文档规范化

`divider.md` 中的「设计 Token」章节改为标准两节结构（`### 全局 Token`），列名统一为「Token 名称 / 说明 / 默认值」，与项目其他组件格式对齐。

  TypeScript 用户在更新依赖后编译期会立即报错提示。
