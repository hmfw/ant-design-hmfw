# v0.29.0

发布日期：2026-07-29

## ✨ 新增功能

### ConfigProvider

- **componentDisabled**：新增全局禁用态下发能力，统一禁用内部控件
- **useMergedDisabled**：抽出共享 hook，合并「控件自身 disabled」与「容器下发 disabled」

  采用「或」语义而非「控件优先」：Vue 的 Boolean prop 会把缺省值归一为 `false`，无法区分「未传」与「显式传 `false`」，因此容器禁用时控件不能单独反禁用 —— 与 AntD 的 `DisabledContext` 行为一致

### Form

- **hasFeedback**：此前仅有接口声明、无任何实现，现补齐四态图标
  - success / warning / error 使用 Filled 图标，`validating` 使用 `LoadingOutlined`
  - 颜色消费 `--hmfw-color-{success,warning,error,primary}` 状态 Token
  - 控件右内边距自动让位，避免长文本排到图标下方

### 容器禁用态接入

- **Button / Checkbox / CheckboxGroup / Input / InputPassword / InputSearch / TextArea / Radio / Select / Switch**：接入 `useMergedDisabled`，使 Form 的 `disabled` 与 ConfigProvider 的 `componentDisabled` 真正作用于内部控件

## 🐛 缺陷修复

### Form

- **必填星号从未渲染**：CSS 使用了直接子代选择器 `>`，但 label 实际包裹在 `.hmfw-form-item-label` 内，导致星号一直不可见。原单测只断言类名存在，未覆盖实际渲染
- **requiredMark="optional" 语义错误**：此前仍显示红色星号，正确语义应为隐藏星号并在非必填项后标注「可选」
- **Demo 误用 validate() 返回值**：3 个 Demo 按布尔值处理 `validate()`，但该方法校验失败时 **throw 错误对象**，已改为 try/catch

## 📖 文档与 Demo

- **Form Demo 6 → 16**，补齐 10 个场景：`size`、`disabled`、`validateTrigger`、组件 Token、`vertical` 布局、`requiredMark` 三态、嵌套字段、复杂控件绑定、弹窗内表单、反馈图标
- Form API 表补充 `hasFeedback` 条目（此前因未实现而缺失）
- 修正 `componentDisabled` 注释与文档：原写「控件自身 disabled 优先」，与「或」语义的实现不符
- 移除顶层一次性审查文档 `RANGE_PICKER_REVIEW.md` / `RANGE_PICKER_FIX_SUMMARY.md`，结论沉淀至对应 commit message

## 📊 质量提升

- Form 抽出 `types.ts`，事件参数类型对外导出；props 补 `satisfies Record<keyof XProps, any>` 约束
- 新增 2 条 `hasFeedback` 单测，覆盖四态图标渲染与「无状态 / 未开启」两种不渲染场景
- 单测总数 2380 → 2382，全部通过

## ⚠️ 已知限制

- **Form `preserve` 仍为空壳**：其语义依赖「字段卸载时从 model 摘除值」，而当前 model 由使用方通过 `v-model` 完全掌控，组件不主动删键，`preserve: false` 无从体现差异。真正实现需引入内部值存储层，属结构性改动，另行立项
